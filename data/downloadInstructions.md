# SFMTA Parking Citations Analysis

This project analyzes time and location patterns for areas with the most parking citations in San Francisco using the SFMTA Parking Citations & Fines dataset.

Dataset source:  
https://data.sfgov.org/Transportation/SFMTA-Parking-Citations-Fines/ab4h-6ztd/about_data

## Download the Dataset

Only citations from **January 1, 2016 to present** are used.

1. Open the dataset link above 
2. Click Actions
3. Click Query
4. Query the dataset based on time from January 1st 2016 to Present 
5. Click **Export → CSV**
